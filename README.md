# TypeScript Command-Line Task Manager

## Overview

As a software engineer, I am expanding my skillset by learning TypeScript, a language that adds static typing to JavaScript. This project represents my journey into type-safe application development.

The **Task Manager** is a command-line application that allows users to create, list, complete, and delete tasks. Tasks are persisted to a JSON file, so they remain available between sessions. This project demonstrates my understanding of TypeScript fundamentals, object-oriented programming, generics, and file I/O with Node.js.

**Purpose:** This software was created to deepen my understanding of TypeScript by building a practical application. Through this project, I gained hands-on experience with:
- Type annotations, interfaces, and type aliases
- Classes with encapsulation and generic types
- Union types for status and priority values
- Module organization with import/export
- File I/O using the Node.js fs module
- Command-line interface with readline
